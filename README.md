# Instruction-Sheet Skeleton

A lean, local-only skeleton for **AI instruction-sheet apps** — built with Kiro for [Kiroween 2026](https://kiroween.devpost.com/) (Skeleton Crew category).

## The pattern

1. A public **instruction sheet** (Markdown) tells the user's own AI chat how to generate data as JSON.
2. The AI returns an **import link**: the JSON, gzip-compressed and base64url-encoded, in a `?data=` query parameter.
3. The app decodes and validates the link, stores the data **locally in the browser** (IndexedDB), and works fully offline afterwards.

No API keys. No server. No AI/LLM API inside the app — generation always happens outside the app, in the user's own AI chat.

## What's in this repo

- `core/` — the skeleton: import-link codec, schema validation, local storage, shared UI parts. Nothing else.
- `apps/player/` — **Pack Player**: imports a listening pack and plays it back with the browser's built-in text-to-speech.
- `apps/board/` — **Memory Board**: imports a memory board and displays it as cards with tag filtering.
- `instructions/` — the two public instruction sheets (AI-agnostic; any chat AI can follow them).
- `samples/` — sample data and import links, generated by following the instruction sheets.
- `.kiro/` — the steering documents and specs this project is built from, spec-first.
