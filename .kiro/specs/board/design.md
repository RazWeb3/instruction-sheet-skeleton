# Design — Memory Board (App 2)

## Overview

One screen under `apps/board/`, built only on `core/`. No build step, no
framework. Read-focused: browse and filter, no in-app editing (corrections
go back to the AI chat via the exported memo).

## Data format

```json
{
  "type": "memory-board",
  "schemaVersion": 1,
  "title": "About Aki (sample)",
  "cards": [
    {
      "heading": "Morning routine",
      "body": "Starts the day with a walk.",
      "tag": "habit",
      "updatedAt": "2026-11-11T00:00:00Z"
    }
  ]
}
```

- `title` (required).
- `cards`: array of `{ heading (required), body (required), tag?,
  updatedAt? (ISO string) }`.
- Validation is `core/validate.js`; the board adds no extra rules.

## Layout (single screen)

- Header: app title.
- List view: imported boards (title only; no card count, matching
  Requirement 2.1). Empty state from
  `core/ui.js` when there are none, with the sample-import button.
- Detail view: tag filter row (all tags present on the board + "all"),
  then cards sorted by `updatedAt` descending (missing `updatedAt` last).
  Each card shows heading, body, and tag when present.
- Footer: "Export correction memo" button producing plain text.

## Export memo

Plain text, e.g.:

```
Board: About Aki (sample)
- [habit] Morning routine: Starts the day with a walk.
```

Generated from the open board only. No extra commentary added.

## Sample

`samples/board-sample.json` — one small board about a **fictional** person
(never Raz's real personal-memory data), generated by following
`instructions/board.md`, with its import link in `samples/` and on the
