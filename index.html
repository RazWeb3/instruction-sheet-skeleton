Instruction-Sheet Skeleton

Hand a public instruction sheet to your own AI chat. Get an import link back. Your data stays in your browser.

A lean, local-only skeleton for AI instruction-sheet apps. No API keys, no server, no AI inside the app.

Pick an app

  • Pack Player

    Import a listening pack and play it back with the browser's built-in text-to-speech.

    Open the app Instruction sheet

    Paste this URL into your AI chat:

    https://raw.githubusercontent.com/RazWeb3/instruction-sheet-skeleton/main/instructions/player.md

  • Memory Board

    Import a memory board and browse it as cards, filtered by tag.

    Open the app Instruction sheet

    Paste this URL into your AI chat:

    https://raw.githubusercontent.com/RazWeb3/instruction-sheet-skeleton/main/instructions/board.md

How it works

  1. Instruction sheetA public Markdown sheet describes the data format.
  2. Your AI chatYour own AI follows the sheet and writes the JSON.
  3. Import linkThe AI returns a link carrying the data.
  4. Local appThe app validates it and stores it in your browser.
